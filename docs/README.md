# NURITEO 공개 문서

이 디렉터리에는 설치자, 운영자, 보안 담당자와 사용자가 제품을 평가하고 운영하는 데
필요한 공개 계약만 포함한다.

## 문서 영역

| 경로 | 내용 |
|---|---|
| [operations](./operations) | 관측성, 지원 번들, 운영 절차와 신뢰성 기준 |
| [release](./release) | 지원 범위, 알려진 제한, 릴리스·출처·장애 대응 계약 |
| [security](./security) | 위협 모델, 워크로드 강화와 취약점 대응 절차 |

내부 기획, 제품 설계, 의사결정 기록, 구현 세션과 출시 승인 증거는 이 공개 저장소의
배포 대상이 아니다.
